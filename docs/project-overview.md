# プロジェクト概要

## 背景

営業活動では、顧客情報、契約・機種の状況、過去の対応、次に行うことが複数の場所や担当者の記憶に分かれると、確認や引き継ぎに手間がかかります。CRM-Proは、営業現場で働く中で見つけたこうした課題をもとに企画・開発している、社内向けの顧客管理・営業支援ツールです。

## プレビューで紹介する主な業務画面

- 顧客プロフィール、担当者、対応履歴の確認
- 機種変更・契約フォロー対象の一覧管理
- 営業予定のカレンダー共有
- 月次実績、カテゴリ別収益、スタッフ別実績の分析
- 見積もりの作成と帳票プレビュー
- スタッフの出退勤と月次タイムシート

画面プレビューは本番UIの構成を参考に描き直した静止画です。実際の本番画面のキャプチャや業務データは含めていません。

## 目指すこと

- 顧客・契約・対応履歴を確認しやすくする
- 次の対応を明確にし、追客の抜け漏れを減らす
- 営業状況と実績を把握し、引き継ぎや判断に活用する
- 現場が無理なく使える業務の流れにする
- 利用者の声と運用状況をもとに改善を続ける

## 進め方

まず利用者の仕事の流れと困りごとを把握し、解決したい課題と優先順位を整理します。そのうえで必要な情報や画面を設計し、実装後は実際の利用者に確認しながら改善します。技術的な選択だけでなく、業務上の効果や継続運用のしやすさも判断材料にしています。

## 担当したこと

- 営業現場の課題発見と業務要件の整理
- 機能の優先順位付けと仕様判断
- AIを活用した設計・実装・レビューの進行
- 利用者の確認を受けた修正と継続改善

この公開ショーケースでは、社内データや実運用上の詳細を避け、取り組みの考え方を説明しています。
