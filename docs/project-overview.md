# プロジェクト概要

## 背景

営業活動では、顧客情報、案件の状況、過去の対応、次に行うことが複数の場所や担当者の記憶に分かれると、確認や引き継ぎに手間がかかります。CRM-Proは、自ら営業現場で働く中で見つけたこうした課題をもとに企画した、社内向けの顧客管理・案件管理ツールです。

## 目指すこと

- 顧客と案件の状況を把握しやすくする
- 次の対応を明確にし、追客の抜け漏れを減らす
- 現場が無理なく使える業務の流れにする
- 利用者の声と運用状況をもとに改善を続ける

## 進め方

まず利用者の仕事の流れと困りごとを把握し、解決したい課題と優先順位を整理します。そのうえで必要な情報や画面を設計し、実装後は実際の利用者に確認しながら改善します。技術的な選択だけでなく、業務上の効果や継続運用のしやすさも判断材料にしています。

## 担当したこと

- 営業現場の課題発見と業務要件の整理
- 機能の優先順位付けと仕様判断
- AIを活用した設計・実装・レビューの進行
- 利用者の確認を受けた修正と継続改善

この公開ショーケースでは、社内データや実運用上の詳細を避け、取り組みの考え方を説明しています。
