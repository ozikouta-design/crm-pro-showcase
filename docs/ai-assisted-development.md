# AIを活用した開発フロー

## 役割分担

### Claude Code

- 業務上の要望や課題を要件に整理
- 設計案と実装方針を検討
- 仕様や変更内容のレビューを支援

### Codex

- 決定した仕様に沿った実装
- テストの作成・実行と不具合修正
- レビューで見つかった改善点への対応

### 人間

- 顧客・利用者の話を聞き、現場の背景を把握
- 課題、優先順位、仕様を決定
- 実際の業務に合うかを利用者と確認
- 公開やリリースを含む最終判断を行う

## 反復の流れ

1. 利用者の仕事と困りごとを把握する。
2. 解決したい課題と成功条件を整理する。
3. AIも使って設計案を検討し、人が仕様を決める。
4. 実装、テスト、レビュー、修正を進める。
5. 利用者が業務の中で確認し、フィードバックを次の改善へつなげる。

AIは作業を速める手段として使い、業務理解や仕様判断、品質の最終確認は人が担います。
